## 遊戲概述

玩家選擇職業、創建角色後進入冒險世界，透過**試煉塔爬塔**或**地圖刷怪**兩種模式進行戰鬥。戰鬥勝利可獲得經驗值、金幣與裝備掉落，升級後可分配六維素質點數以強化角色。

---

## 如何開始

1. 直接用瀏覽器開啟 `index.html`（建議使用支援 ES Module 的現代瀏覽器）
2. 選擇職業 → 輸入角色名稱 → 開始冒險
3. 遊戲進度自動存儲於瀏覽器 `localStorage`

## 六維素質系統

每次升級獲得 **5 點**自由分配點數，可投入以下六項素質：

| 素質 | 效果說明 | 係數 |
|------|----------|------|
| **STR（力量）** | 增加物理攻擊力 | 每點 +2 ATK |
| **AGI（敏捷）** | 降低攻擊冷卻時間 | 每點 -10ms 冷卻 |
| | 增加閃避率 | 每點 +0.5% 閃避 |
| **VIT（體質）** | 增加最大 HP | 每點 +10 HP |
| | 增加防禦力 | 每點 +0.4 DEF |
| | 擴充背包容量 | 每 5 點 +1 格 |
| **INT（智力）** | 增加魔法攻擊力 | 每點 +2 MATK |
| | 增加 SP 上限 | 每點 +5 SP |
| | 增加 SP 回復 | 每點 +0.05 回復 |
| **DEX（靈巧）** | 增加命中率 | 每點 +0.8% 命中 |
| | 降低冷卻時間 | 每點 -1% CD |
| **LUK（幸運）** | 增加暴擊率 | 基礎 3% + 每點 +0.3% |
| | 增加閃避率 | 每點 +0.2% |

### 衍生屬性

| 衍生值 | 公式 | 上限 |
|--------|------|------|
| 暴擊率 | `3% + LUK × 0.3%` | 50% |
| 暴擊倍率 | 固定 **1.5 倍** | — |
| 閃避率 | `LUK × 0.2%` | 50% |
| 攻擊冷卻 | `1000ms - AGI×10 - 裝備SPD×8` | 最低 120ms |

## 戰鬥系統

### 戰鬥模式

1. **試煉塔**：逐層推進，勝利層數 +1，敗退層數 -1（最低第 1 層）
2. **地圖刷怪**：選擇特定區域重複戰鬥，不影響塔層進度

### 回合機制

採用**速度比行動配額制**：

- 每輪玩家行動次數 = `floor(玩家速度 / 敵人速度)`（最少 1 次，最多 5 次）
- 玩家全部行動完畢後，敵人進行 1 次攻擊
- 循環直到一方 HP 歸零

### 可執行動作

| 動作 | 說明 |
|------|------|
| ⚔️ 攻擊 | 普通物理攻擊（支援按住持續攻擊） |
| 💥 技能 | 使用職業技能（法師以 MATK 計算） |
| 🛡️ 防禦 | 本回合受到傷害減半 |
| 🏃 逃跑 | 70% 機率成功逃脫戰鬥 |

## 傷害與防禦公式

### 攻擊傷害計算

```
基礎傷害 = totalATK × (ATK_SCALE / (ATK_SCALE + 敵方DEF))
         = totalATK × (50 / (50 + 敵方DEF))
```

- 若觸發暴擊：`最終傷害 = 基礎傷害 × 1.5`

### 法師技能傷害

```
raw = (effectiveMatk + totalATK × 15%) × 技能倍率(1.5)
最終傷害 = raw × (50 / (50 + 敵方DEF))
```

### 玩家受傷計算

```
實際傷害 = 來源傷害 × (DEF_SCALE / (DEF_SCALE + totalDEF))
         = 來源傷害 × (100 / (100 + totalDEF))
```

- 最低傷害為 1
- 若防禦狀態：來源傷害先減半再代入公式
- 閃避判定先於傷害計算（閃避成功 = 0 傷害）

### 怪物防禦值

若怪物模板未定義 DEF，則自動產生：
```
怪物DEF = floor(怪物最大HP × 8%)
```

### 101 層以上怪物強化公式

```
倍率 = 1 + ceil((層數 - 100) / 100)
HP   = 3000 + 原始HP × 倍率
ATK  = 200 + 原始ATK × 倍率
SPD  = 50 + min(100, 原始SPD × 倍率)
EXP  = 3000 + 原始EXP × 倍率
Gold = 2000 + 原始Gold × 倍率
掉率 = min(0.95, 原始掉率 + 倍率 × 0.04)
```

### 怪物成長曲線（所有層數）

戰鬥時根據波數（wave）對怪物素質進行對數緩增：
```
waveMultiplier = 1 + ln(1 + wave) × 0.30
怪物HP  = floor(模板HP × waveMultiplier)
怪物ATK = floor(模板ATK × waveMultiplier)
金幣倍率 = 1 + ln(1 + wave) × 0.15
```

## 物品稀有度與掉寶機率

### 稀有度等級

| 稀有度 | 顏色 | 屬性倍率 |
|--------|------|---------|
| 普通 (Common) | ⚪ 白色 | ×1.0 |
| 稀有 (Uncommon) | 🟢 綠色 | ×1.5 |
| 極品 (Rare) | 🔵 藍色 | ×2.0 |
| 傳說 (Epic) | 🟣 紫色 | ×3.0 |
| 神話 (Legendary) | 🟡 金色 | ×5.0 |

### 掉落機率系統

戰鬥勝利後的掉落判定流程：

1. **掉落嘗試次數** = `1 + floor(wave / 30)`
2. 每次嘗試從**全物品池**隨機選取一個模板
3. 計算最終掉落機率：

```
waveBonus = 1 + wave × 0.5%
最終掉率 = min(0.95, 怪物基礎掉率 × 稀有度權重 × waveBonus)
```

### 稀有度掉落權重

| 稀有度 | 掉落權重 | 含意 |
|--------|---------|------|
| 普通 | 2.0 | 最容易掉落 |
| 稀有 | 1.2 | 常見 |
| 極品 | 0.5 | 較稀少 |
| 傳說 | 0.20 | 稀有 |
| 神話 | 0.06 | 極為稀有 |

### 掉落範例計算

假設第 50 層擊敗龍（基礎掉率 50%）：
- 嘗試次數：`1 + floor(50/30) = 2` 次
- waveBonus：`1 + 50 × 0.005 = 1.25`
- 嘗試掉落神話物品：`min(0.95, 0.50 × 0.06 × 1.25) = 3.75%`
- 嘗試掉落普通物品：`min(0.95, 0.50 × 2.0 × 1.25) = 0.95`（觸頂 95%）

## 物品工廠與修飾詞系統

掉落或商店生成的物品並非固定數值，而是透過**物品工廠**產生獨特實例。

### 屬性浮動

每個物品依稀有度具有不同的屬性隨機浮動幅度：

| 稀有度 | 浮動幅度 |
|--------|---------|
| 普通 | ±18% |
| 稀有 | ±12% |
| 極品 | ±8% |
| 傳說 | ±5% |
| 神話 | ±3% |

### 等級縮放

物品屬性隨掉落時的層數放大：

- **1-20 層**：指數成長 `(1.035)^(level-1)`
- **21-100 層**：對數補償，避免過早爆炸
- **101+ 層**：固定 ×4 倍率

### 修飾詞（前綴）系統

物品有機率附帶 0~2 個修飾詞：

| 機率 | 修飾詞數量 |

## 升級與成長機制

### 經驗值需求

```
下一級所需 EXP = 當前所需 × 1.35
初始值 = 100
```

| 等級 | 累計 EXP 門檻（約） |
|------|-------------------|
| 1→2 | 100 |
| 2→3 | 135 |
| 3→4 | 182 |
| 5 | ~333 |
| 10 | ~2,106 |

### 升級獎勵

每次升級：
- MaxHP +20
- ATK +5
- DEF +2
- SPD +1
- 獲得 **5 點**自由分配素質點數
- HP 完全回復

### 經驗值獲取

戰鬥勝利時的 EXP 隨波數對數增加：
```
expMultiplier = 1 + ln(1 + wave) × 0.5
實際EXP = floor(怪物基礎EXP × expMultiplier)
```

## 存檔系統

- 使用瀏覽器 `localStorage` 自動存檔
- 存檔 Key：`brave_hero_save_data`
- 每次金幣/經驗/裝備變動自動觸發儲存
- 儲存內容：角色基礎屬性、六維素質、裝備、背包、塔層進度
- 可在齒輪選單中「重置遊戲」清除所有存檔

## 自動刷怪外掛

遊戲內建自動戰鬥功能，可從齒輪選單開啟：

### 功能

1. **自動爬塔**：持續挑戰試煉塔，勝利自動推進至下一層
2. **地圖自動刷怪**：選擇特定地圖重複戰鬥刷取經驗與裝備

### 行為

- 自動在玩家回合執行「普通攻擊」
- 戰鬥結束自動開始下一場
- 戰敗時自動重新載入（等同於重生）
- 可隨時按下「停止自動」按鈕中斷

## 技術架構

```
rpg_battle/
├── index.html              # 主頁面（場景結構）
├── css/style.css           # 遊戲樣式
└── js/
    ├── main.js             # 遊戲主控制器（Game class）
    ├── data.js             # 靜態資料（職業、物品、怪物、地圖）
    ├── stats_config.js     # 素質係數與平衡參數
    ├── player.js           # 玩家類別（屬性、裝備、背包）
    ├── enemy.js            # 敵人類別
    ├── battle.js           # 戰鬥引擎（回合、傷害、掉落）
    ├── equipment.js        # 裝備管理器
    ├── item_factory.js     # 物品實例生成（浮動、修飾詞）
    ├── ui.js               # UI 管理
    ├── save_manager.js     # 存檔管理（localStorage）
    └── auto_battle_plugin.js # 自動刷怪外掛
```

- 純前端 ES Module 架構
- 無外部相依套件
- 支援行動裝置（響應式設計）
